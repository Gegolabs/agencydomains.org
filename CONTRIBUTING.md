# How to give feedback · Cómo dar feedback

**This trilogy is written in public and actively invites critique.** No comment is too small, and you do **not** need a GitHub account to be heard. Pick whichever door is easiest for you.

*Esta trilogía se escribe en público y busca crítica activamente. Ningún comentario es demasiado pequeño, y **no** necesitas una cuenta de GitHub para que te escuchemos. Usa la puerta que te resulte más fácil.*

---

## 1. Just write — no account needed · Solo escribe — sin cuenta

The lowest-friction door, open to everyone:
**[cesar.obach@ultrabase.net](mailto:cesar.obach@ultrabase.net?subject=Feedback%20%E2%80%94%20agencydomains.org)**

A reaction, a disagreement, a typo, a "this resonates / this doesn't" — all welcome.

*La puerta de menor fricción, abierta para todos. Una reacción, un desacuerdo, una errata, un "esto resuena / esto no" — todo bienvenido.*

## 2. Open an issue · Abre un tema (GitHub)

For something trackable — an error, a concrete suggestion, a conceptual discussion:
**[Open an issue →](https://github.com/gegolabs/agencydomains.org/issues/new)**

*Para algo rastreable — un error, una sugerencia concreta, una discusión conceptual.*

## 3. Propose a change · Propón un cambio (pull request)

The books are licensed **GNU FDL v1.3** and live in this repository. Sources are in
`src/<book>/` (`contenido/` ES, `contenido-en/` EN). If you want to propose exact wording,
**open a pull request** against the source — never the generated output (`_dist/`).

*Los libros están bajo **GNU FDL v1.3** y viven en este repositorio. Las fuentes están en
`src/<libro>/`. Si quieres proponer texto exacto, **abre un pull request** contra la fuente —
nunca contra lo generado (`_dist/`).*

---

There are no walls here: if none of these fit, reach out however you can. The point is the
conversation, not the channel.

*Aquí no hay paredes: si ninguna de estas calza, contáctame como puedas. Lo que importa es la
conversación, no el canal.*
