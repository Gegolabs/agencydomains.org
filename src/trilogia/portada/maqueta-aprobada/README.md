# Maqueta aprobada de las portadas

La vara visual de las portadas de la trilogía, tal como César la aprobó el
2026-10-26: `portadas-trilogia-muestra.png` (los cuatro libros lado a lado) y
las páginas HTML de las que salió (`portada-II/III/IV.html`, y el fragmento del
Libro I, cuyo CSS vive en su propio repo).

Es referencia, no fuente: las portadas que entran a los PDF salen de
`../portada.css` y `../<libro>-<es|en>.html`, que conservan la maqueta y le
suman el refuerzo del tomo marcado en la pila (más grueso y con borde crema
pleno).

Los textos de los HTML de esta carpeta siguen las decisiones de César del
2026-10-27 (subtítulos «Arquitectura Agentiva» y «Camino Agentivo»; sello
Soveria Press): la maqueta que se aprobó es la composición, no esas palabras.
El PNG de muestra conserva los textos del 26-10.
