Vergis

The keys: the reference implementation of AgencyDomains, as open source.

The AgencyDomains books describe a world in which AI agents take over the work of moving information — the work people do today by jumping from one application to another. Vergis is the software that makes that world run: the platform where the agents live, together with the pieces of software they work with, under declared permissions and with a record of every act.

If AgencyDomains is the blueprint, Vergis is the building raised from it, with the door open: anyone can download it, read it, run it and improve it. It is not a model to learn from and then throw away: it is the base designed to run in production.

What does it include today?
The Botler, the container where Botlets run — the pieces of software that do the work; it is generic: it knows nothing about the business of whoever uses it. And its first Botlets: Mira, which produces information, and Daftar, which administers and grades assessment instruments.

Where does it fit?

The Agentive Technology pillar is piece A of the Agentive World, alongside the four books. The books answer why now, where we are going, which way and how we get there; Vergis answers what to start with today. It is not a book: it is code, under AGPL-3.0, and its documentation is under the GNU FDL v1.3.
