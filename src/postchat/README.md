## Composición (la fusión)

Un libro, dos partes — el diseño que produjo la revisión de Vitor (doc 006):

```
Prefacio                      la película que nadie filmó · cómo leer (2 partes)
PARTE 1 · LA PELÍCULA         el martes de Elena, 7:00 → Nocturno
  escenas con teaser          cada escena cierra con un párrafo → comentario
  15:40 · Los zapatos         beat nuevo: salir del modo + privacidad
  Epílogo-bisagra             las tres liberaciones + invitación a la Parte 2
PARTE 2 · EL COMENTARIO       el desarrollo completo, capítulos 1–6 + conclusión
Referencias
```

**Reglas:** la película basta por sí sola (hiperclaridad declarada en todos
lados); los teasers siembran y apuntan, el comentario desarrolla; el modo se
llama **modo agentivo** (doc 007). Build oneside — sin páginas en blanco
(edición online; la print-ready twoside queda como build futuro).

Las variantes v0.1 (`../libro-postchat-narrativo-v0.1/` y
`../libro-postchat-descriptivo-v0.1/`) se preservan como caminos evaluados.
