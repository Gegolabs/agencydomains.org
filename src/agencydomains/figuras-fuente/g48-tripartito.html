Patrón tripartito · Cloud + Cliente + Local

Figura G43 · imagen-firma

Cloud

Control plane

operado por el proveedor de la plataforma agentiva

LicenciasGestión de cuotas, planes, billing
Registry de providersCatálogo de proveedores disponibles
Integración upstreamConexión a proveedores de cognición
Telemetría agregadaMétricas cross-tenant con privacidad preservada
El ecosistema se mantiene donde el proveedor puede operarlo

Cliente

Governance plane

desplegado dentro de la red interna de la empresa cliente

Políticas corporativasDefinición y enforcement (CRUDLEX, umbrales)
Identity providerIntegración con IdP corporativo (OAuth2 / SAML)
Auditoría centralAppend-only log inmutable encadenado
Conexiones internasAcceso a sistemas operacionales del cliente
La política se define donde la empresa controla

Local

Execution plane

en el dispositivo de cada usuario

Cliente MCPClaude Code · Cursor · Windsurf · cualquier cliente conforme
Providers localesConexión a recursos del dispositivo del usuario
Credenciales localesEncriptadas en el dispositivo del usuario
Ejecución de toolsMaterialización efectiva de la acción
La IA opera donde el usuario trabaja
Los tres planos cooperan, pero ninguno sustituye a los otros — la separación es la propiedad fundamental.
