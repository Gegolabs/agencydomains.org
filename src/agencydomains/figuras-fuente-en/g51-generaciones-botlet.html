More generation does not mean more live regeneration

G3 capacity is better spent producing G1 reuse
G1Configures
The agent configures pre-forged proto-Botlets. All the code already lives in the catalog.
→
G2Co-writes
The agent co-writes proto-Botlets: it extends and adapts code alongside the existing catalog.
→
G3Generates
The agent generates the complete code (asymptotic, frontier of the state of the art).
The architecture is the same; what changes is the scope of Engineering.
Two distinct axes — not the same arrow
G3 capacity is better spent producing G1 reuse — the destiny is a richer G1 catalog, not live regeneration.
For platform proto-Botlets, G1 is terminal by design: the generic code already covers N functions; configuring is enough.
More generation ≠ more regeneration — the state of the art serves reuse; it does not replace it.
