When does the agent offer a Facet? · canonical invocation heuristics

Low-dimensionality information → conversation
High-dimensionality information → Facet
Hard to verbalize (color · position · shape) → Facet
The user already has it in visual form → Facet
Comparison across multiple options → Facet
Open-ended creative work → canvas Facet
