Chapter 4 · §2 · Botlets

The 95 / 4 / 1 cycle — the agent's muscle memory

Figure G20 · signature image
95/4/1
typical distribution of a production Botlet's operating life cycle
95%

Normal execution

The Botlet runs as traditional code. Without invoking cognition. This is what sustains the agentive system's economics — one to two orders of magnitude below inference cost.

4%

Change detected in the environment

The Botlet fails or returns an anomalous result. The cognition activates, evaluates the change, decides whether to regenerate, execute manually, or escalate to the human.

1%

Botlet regeneration

The cognition generates a new, adapted version. It replaces the previous one. The cycle starts again — with code updated to the new environment.

Fallback guarantee (non-negotiable) If a Botlet fails catastrophically, the cognition executes the task manually. The process never stops.
