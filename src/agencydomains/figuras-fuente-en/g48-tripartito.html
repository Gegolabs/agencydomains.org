Chapter 7 · Trust Infrastructure operationalized

Tripartite pattern · Cloud + Client + Local

Figure G43 · signature image

Cloud

Control plane

operated by the agentive platform's provider

LicensesQuota, plan, and billing management
Provider registryCatalog of available providers
Upstream integrationConnection to cognition providers
Aggregated telemetryCross-tenant metrics with privacy preserved
The ecosystem stays where the provider can operate it

Client

Governance plane

deployed inside the client company's internal network

Corporate policiesDefinition and enforcement (CRUDLEX, thresholds)
Identity providerIntegration with the corporate IdP (OAuth2 / SAML)
Central auditImmutable chained append-only log
Internal connectionsAccess to the client's operational systems
Policy is defined where the company controls

Local

Execution plane

on each user's device

MCP clientClaude Code · Cursor · Windsurf · any conformant client
Local providersConnection to the user's device resources
Local credentialsEncrypted on the user's device
Tool executionEffective materialization of the action
The AI operates where the user works
The three planes cooperate, but none replaces the others — the separation is the fundamental property.
