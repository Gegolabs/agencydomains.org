Good for: humans querying data via dashboards. Not good for: agents querying to reason autonomously.

Varnished Kimball · 2026

Source ERPs · CRMs · transactional systems
↓
ETL extract · transform · load
↓
Presentation data marts · facts + dimensions
↓
BI Apps dashboards · reports
↓
AGENT NEW semantic queries · autonomous reasoning
↓
Human converses with the agent
Metadata + Semantic Layer + Trust Score + AI Certification NEW strategic asset (cross-cutting)
The data model goes from report container to strategic asset over which agents reason. Without a semantic layer, agents hallucinate on >80% of queries.
