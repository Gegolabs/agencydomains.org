Three dimensions · one intersection

Per user What CRUDLEX the human on whose behalf the agent acts holds. The agent can never exceed the permissions of whoever invokes it.
Per agent What CRUDLEX the agent holds over the system's resources, per its role. Different agents, different permissions over the same resources.
Per context Additional CRUDLEX enabled or restricted by operating context — schedule, location, urgency, session.
Practical case: the user holds R + L; the agent holds C R U D L E; the context requires business hours.
→ If the operation is attempted at 11:00 pm, effective CRUDLEX = ∅.
→ If it is at 2:00 pm, effective CRUDLEX = R + L (intersection with the user's permissions).
